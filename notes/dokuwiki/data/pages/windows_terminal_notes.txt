==== launch multiple tabs with different working directories ====
Using Win+R
<code>
wt -d dir1 ; new-tab -d dir2
</code>

For example
<code>
wt -d work ; new-tab -d work/github
</code>

Sample bat script
<code>
raju@DESKTOP-CRLPVE5 MINGW64 ~/work/windows_terminal
$ cat start_windows.bat
@echo off
setlocal
set "DIR1=%USERPROFILE%\work"
set "DIR2=%USERPROFILE%\work\github"
set "DIR3=%USERPROFILE%\x\foo bar baz\abc"

set TAB1=-p "Git Bash" -d "%DIR1%"
set TAB2=-p "Git Bash" -d "%DIR2%"
set TAB3=-p "Git Bash" -d "%DIR3%"

wt.exe %TAB1% ; new-tab %TAB2% ; new-tab %TAB3%
</code>

Sample shell script: https://github.com/KamarajuKusumanchi/rutils/blob/master/bin/windows/launch_tabs.sh

Sample python script: https://github.com/KamarajuKusumanchi/rutils/blob/master/bin/windows/launch_tabs.py
